# PR title

feat: release v0.3.0 local-store ordering

# PR body

## What does this change?

Promotes local-store ordering from the Phở reference demo into Tiemora Core v0.3.0:
dine-in with table validation, opening hours, ASAP orders, daily stock, staff sold-out
controls, an Order Queue and multi-item orders repriced by the server. Existing single-item
requests remain supported; dine-in and ASAP default off and stock defaults to a lifetime total.

Demo configuration, copy and artwork are isolated under `examples/pho-demo/`, selected by
`npm run build:pho-demo`. The standard config and Wrangler file retain their generic defaults.
This also includes storefront copy overrides, environmental hero layout, Turnstile/VAPID
setup helpers, updated documentation and package version 0.3.0.

## Why?

A local shop needs service-day stock, immediate orders and table handover alongside scheduled
pickup. These capabilities reuse the existing order model without changing rental bookings.
The cart UI ships, but its state/storage contract remains provisional; mixed fulfillment,
combined order/booking checkout and QR sheet generation remain deferred.
