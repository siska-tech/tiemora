# PR title

feat: release v0.4.0 timed rentals and inventory timelines

# PR body

## What changes?

Rental stores can accept timed rentals and fitting visits, reserve inventory through
turnaround, manage handoff exceptions and inspect per-item availability timelines.
Optional additional-day pricing, holiday handoff calendars, customer rental terms and
staff digests extend the rental workflow while retaining existing untimed bookings.

Timed edits now keep inventory holds consistent with the chosen dates. Adjacent
fittings remain selectable in the admin; repeated requests are distinguished by time,
purpose and size. Closed-day validation, fixed/offset pickup slots, confirmation times
and midnight digest delivery have regression coverage.

## Migration

Back up the store database, retain store-specific configuration and bindings, and apply
pending migrations `0010` through `0013` before deploying the Worker and assets.
`0012` rebuilds inventory while preserving assigned items. Existing booking intervals,
orders and order lines are covered by the populated v0.3 upgrade test. Already upgraded
stores need no extra migration for the common fixes. Released migrations are unchanged.

See v0.4.0 upgrade notes `docs/releases/v0.4-result.md` for the deployment order,
verification steps and rollback considerations.

## Validation

- Lint, typecheck, all 233 tests and the standard build via `npm run check`.
- Isolated Phở demo build and standard Worker deployment dry-run.
- Populated upgrade checks include preserved rows, legacy intervals, indexes,
  foreign keys and SQLite integrity.

These are local results; the final PR commit still requires GitHub CI. This release
preparation does not deploy or migrate any remote database.
